Topic: (HOLCF, bug, patch) theorems fail to load into subclass

Alex Mobius (Oct 20 2026 at 15:02):

Hello,
I have written a couple of times here about this bug, which I believe I have a fix for now. Essentially, raising the default sort lf a class context (like HOLCF class bifinite does, raising it from type to cpo) leads to the class context failing to import theorem definitions from superclasses, leaving instead locale versions that refer to locale fixes (e.g. po.below instead of global below :: 'a::po => 'a => bool). The fix is relatively straightforward - when assembling the class context, cast the 'a type variable in the definitions to the right sort. This is sound, because subclasses necessarily have higher sort for that variable than superclasses. The small patch and the reproduction suite are attached, checked against the newest RC3. I would really appreciate if someone could take a look.

class-base-sort-syntax.patch
