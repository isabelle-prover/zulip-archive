Isabelle2026 is now available.

This version introduces many changes over Isabelle2025-2: see the
NEWS file for further details. Here are notable details:

  • Support for inlined theory options and conditional developments.

  • Improved support for Apple Silicon, without Intel emulation.

  • Improved control over prover output in batch-builds.

  • Many Isabelle/jEdit improvements, notably for Accessibility (NVDA).

  • Many Isabelle/VSCode improvements, notably HTML-based GUI via Scala.js.

  • HOL: various improvements to code generation.

  • HOL: various improvements of theory libraries, notably HOL-Analysis.

  • HOL: additional library material, notably HOL-New_Algebra.

  • HOL: updates and improvements of Sledgehammer and external provers.

  • HOL: various improvements of SMT support, with cvc5 proof reconstruction.

  • ML: 64_32 mode now supports 32 GiB heap instead of 16 GiB.

  • ML: sanity checks for string literals vs. formal names.

  • ML: minor improvements of kernel integrity.

  • System: improved logging of Isabelle/Scala and Isabelle/ML.

  • System: support for Scala.js with many Isabelle/Scala modules.

You may get Isabelle2026 from the following mirror sites:

Cambridge (UK) https://www.cl.cam.ac.uk/research/hvg/Isabelle
Munich (Germany) https://isabelle.in.tum.de
Sydney (Australia) https://proofcraft.systems/isabelle/index.html
Potsdam, NY (USA) https://mirror.clarkson.edu/isabelle
