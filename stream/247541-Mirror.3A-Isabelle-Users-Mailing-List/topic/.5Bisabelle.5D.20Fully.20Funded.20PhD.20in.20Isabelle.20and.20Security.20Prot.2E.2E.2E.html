Subject: [isabelle] Fully Funded PhD in Isabelle and Security Protocol Verification (University of Exeter, UK)

Dear list,
I am looking for an enthusiastic PhD student to join me at the University of Exeter and work on a fully funded project on:
End-to-End Verification of Security Protocols in Isabelle
The project explores the use of Isabelle/HOL to develop machine-checked proofs of security protocols, aiming to connect high-level protocol models with implementation-level correctness arguments. The work will contribute to the development of scalable techniques for theorem-prover-based security verification.
Ideal candidates will have interests in:

* Isabelle/HOL and interactive theorem proving
* Formal methods
* Security and cryptography
* Program verification
* Logic and semantics
