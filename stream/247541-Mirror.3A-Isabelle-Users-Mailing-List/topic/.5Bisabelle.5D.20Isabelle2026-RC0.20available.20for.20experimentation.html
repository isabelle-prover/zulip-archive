Dear Isabelle users,

following the usual routine, the next Isabelle release is scheduled for
mid-October 2026. See the detailed timetable
https://sketis.net/2025/plan-for-isabelle2026-october-2026 and the ongoing
documentation of the release process
https://sketis.net/2026/release-candidates-for-isabelle2026

According to plan, we now have an early preview, 4 weeks before the formal
start of the release process: https://isabelle.in.tum.de/website-Isabelle2026-RC0

The NEWS file is already in decent form, but several items are still missing.
The ANNOUNCE file has not been done yet.

Note that there have been significant changes for the desktop application
launcher, both on macOS and Windows. Also note that macOS is now separate for
Apple Silicon (ARM) versus Intel.

Any E-Mail feedback on release candidates should use a proper Subject: line
and not just a clone of this announcement.

Makarius

Dear Isabelle users,

just a side-remark on the release process: the time-table is given here
https://sketis.net/2025/plan-for-isabelle2026-october-2026

We are presently in the stage between RC0 and RC1, where the status-quo is
wrapped up and put into a form that can make the start of the actual release
process.

Many things that are already "comitted" for Isabelle2026 need to be finalized;
some will not make it and be postponed (again).

This is a very bad time to propose new features. It would essentially mean to
"jump the queue" in a rude manner.

The proper time for new things is after a release, lets say at a few
weeks/months distance from it.

Makarius
