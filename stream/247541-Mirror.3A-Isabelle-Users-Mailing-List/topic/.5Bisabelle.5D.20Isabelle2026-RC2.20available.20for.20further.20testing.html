Topic: [isabelle] Isabelle2026-RC2 available for further testing

Email Gateway (Sep 27 2026 at 19:42):

From: Makarius <makarius@sketis.net>

Dear Isabelle users,

this is a routine update of the current line of release candidates that will
soon converge towards final Isabelle2026 (October 2026). There have been many
small changes, see https://sketis.net/2026/release-candidates-for-isabelle2026
for further details. Some documentation still needs to be updated, and a few
technical problems remain.

The current release candidate is available from
https://isabelle.in.tum.de/website-Isabelle2026-RC2

A corresponding version of the Archive of Formal Proofs is
https://foss.heptapod.net/isa-afp/afp-devel/-/commit/ba00eb27d5b9

Any feedback about Isabelle release candidates should be posted with a
meaningful Mail subject, not just a clone of this announcement.

Makarius
