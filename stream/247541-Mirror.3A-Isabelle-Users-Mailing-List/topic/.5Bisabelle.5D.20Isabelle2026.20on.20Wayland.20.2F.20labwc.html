From: Florian Haftmann <florian.haftmann@cit.tum.de>

Hi all,

when using Isabelle2026 on Wayland with labwc as compositor, the ui area
of Isabelle/jEdit does not adjust to the surrounding window, cf.
attached screenshot.

This can be work-arounded by putting Isabelle/jEdit to fullscreen, but
this does not resolve the problem for undocked panels.

It seems that Isabelle/jEdit is running under XWayland, which is maybe
not what is intended.

Are others experiencing similar issues?

Am I missing some settings?

I am using labwc 0.8.3 on Debian 13.

Thanks a lot,
Florian

From: Jan van Brügge <jan@vanbruegge.de>

Hi Florian,

the same thing happens on swaywm, you need to set the env var
_JAVA_AWT_WM_NONREPARENTING=1 for this to work.

Cheers,
Jan
