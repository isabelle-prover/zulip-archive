This crashes in Isabelle 2026 and I think it also does in earlier versions:

theory Scratch
imports Main
begin

simproc_setup congproc p ("id id True") = ‹K (K (K (SOME @{lemma "id id True ≡ True" by simp})))›

lemma "id id True" by simp

end

transitive: middle term
id id True ≡ True
id id True ≡ id True
