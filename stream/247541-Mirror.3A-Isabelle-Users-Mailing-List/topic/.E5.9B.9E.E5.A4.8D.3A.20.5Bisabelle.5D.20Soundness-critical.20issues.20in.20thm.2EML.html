Dear Isabelle users

I’ve written a patch for this issue and uploaded it to my conda channel. If this issue affects you, you can install the patched version with:

conda create -n <env-name> -c https://conda.qiyuan.me isabelle-bicompose-rename-fix
conda activate <env-name>
isabelle jedit

(Replace <env-name> with any environment name you like.)
isabelle-bicompose-rename-fix is a separate package built on top of the package isabelle which contains the original, unmodified Isabelle. To revert to the original version at any time, simply runconda remove isabelle-bicompose-rename-fix

Alternatively, if you’d prefer to apply the fix yourself, the patch is below:

--- a/src/Pure/thm.ML
+++ b/src/Pure/thm.ML
@@ -2578,10 +2578,10 @@ fun bicompose_aux opt_ctxt {flatten, match, incremented} (state, (stpairs, Bs, B

         if lifted then

-          (case rename_bvars dpairs tpairs B As0 of
+          (case rename_bvars dpairs (rtpairs @ tpairs) Bi As0 of

               let fun proof p = Same.commit (Proofterm.map_proof_terms_same term I) p;

-              in (map (strip_apply (Same.commit term) B) As0, deriv_rule1 I proof rder) end
