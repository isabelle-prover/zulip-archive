Topic: NEWS: Theory conditions allow for predicates with arguments

Email Gateway (Nov 12 2026 at 21:42):

From: Makarius <makarius@sketis.net>

* General *

  • Theory conditions allow for predicates with arguments: as literal
    strings or cartouches. For example, getenv("A","B","C") to check process
    environment variables (settings). The $A syntax is still supported as
    before, but now expands to getenv("A"); the latter form needs to be
    used, if A is not an identifier.

  • The syntax for system option values now allows cartouches as well, to
    facilitate nested strings such as [condition = ‹getenv("A")›].

This refers to Isabelle/039bf110de16, with documentation in the "system" manual.

In the next round, hopefully soon, there will be support form "branched PIDE
documents", e.g. to let Isabelle/jEdit operate on different "worlds" with
different conditions in the same session. There are many more applications of
this idea, e.g. exploring / editing SCM history with live PIDE support.
