Subject: Timeout.apply not interrupting in a forked thread (since 86049:b6e33c2b52c9)

Hi all,

since 86049:b6e33c2b52c9 (10.11.2026), Timeout.apply no longer
interrupts Future.join in a forked thread. An example is attached below.

Best wishes,

Kevin

isabelle
theory Scratch
imports Pure
begin

ML \<open>
val start = Time.now ()
val _ = Isabelle_Thread.join (Isabelle_Thread.fork
(Isabelle_Thread.params "test" |> Isabelle_Thread.interrupts) (fn () =>
Timeout.apply (seconds 1.0) (fn () =>
Future.join (Future.fork (fn () => Time.sleep (seconds 5.0)))) ()
handle Timeout.TIMEOUT _ => ()))
val _ = writeln (Time.toString (Time.now () - start))
\<close>

end
