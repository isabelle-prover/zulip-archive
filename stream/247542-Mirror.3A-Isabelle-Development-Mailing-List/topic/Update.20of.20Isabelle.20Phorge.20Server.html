The Isabelle Phorge Server is described in the "system" manual chapter 6, but
I am probably the only reader (and writer) of that text.

I have now updated our instance https://isabelle-dev.sketis.net from Ubuntu
22.04 to 24.04 (and tried 26.04 without success). So it is now the pretty
stable Ubuntu 24.04, for a few more years of support by Canonical.

The Phorge server works well as an improved replacement for the classic hgweb
interface, with a few add-ons like announcement channels, blogs, trackers etc.
It also aggregates several repositories: isabelle-dev, afp-devel,
isabelle-website, polyml.

Neither hgweb nor Phorge will withstand the ongoing aggression of AI bots on
the web (without further measures that I have omitted here). Instead, the
service is non-public: it requires explicit membership.

People who think they should have an account, but don't find it or have never
asked for it, can send me a private e-mail. I need a formal user name,
informal real name, canonical mail address. For example: john.doe, John Doe,
john@doe.org

As a bonus, there are some new "Tasks" on the tracker (which would be called
"Issues" elsewhere): A collection of breakdowns of the initial higher-order
natural-deduction engine by Larry Paulson (approx. 1990), which was the reason
why the system was called "Isabelle" in the first place. These
machine-generated attacks on the seminal work by Larry were sent to me shortly
before and after the Isabelle2026 release, and by quite different people ---
I've told everybody that such old problems are no reason to stop the release
train.

We have now 1-2 release cycles to sort out the rubble ...

Makarius
